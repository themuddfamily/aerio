# Aerio development roadmap

Updated: 2026-10-17. Open work below adds features found in eM Client 11.0.1201 that are missing or only partly implemented in Aerio. E31-E48 continue the completed E01-E30 series.

The comparison, REA artifact identities, exact code/resource observations, official references, and current Aerio boundaries are recorded in [the follow-up parity evidence](docs/em-client-parity-followup.md). Static evidence establishes shipped structures and code paths; live provider behavior has not been tested. Implementation details and acceptance criteria below are Aerio requirements.

Completed work is recorded in [CHANGELOG.md](CHANGELOG.md) and the feature documents under [docs/](docs/). The [earlier comparison](docs/em-client-parity.md) remains the historical evidence for E01-E30.

## Mail organization and usability

- [ ] **E31 — Automatic archiving of old mail into Local Folders.** Add an opt-in, recurring policy with account/folder scope, message-age cutoff, run frequency, exclusions, preview, and Run now. Reuse Local Folders storage/transfer primitives and add a durable archive-job queue; verify that eligible messages' original MIME and attachments are saved before removing their server copies. Preserve newer or excluded messages in the same conversation instead of using whole-thread Trash. Record progress, failures, and the next run, and resume after restart. Existing Archive actions, disconnected-account archives, and once-per-message rules do not provide this recurring age-based sweep. **Checks:** messages crossing the age cutoff without new mail, mixed-age threads, scope/exclusions, interrupted transfers, disk failures, and duplicate-free resume. **Docs:** explain local-only access, server removal, backup, and operation while Aerio is closed. Evidence: F0 and the archiving documentation.

- [ ] **E32 — Find and clean up existing duplicate mail, events, and tasks.** Add a scoped scanner with candidate groups, matching reasons, a comparison preview, keeper selection, and skip/review actions. Reuse provider queues and supported Trash/undo operations; preserve distinct attachments, recurrence exceptions, and task children. Do not treat Gmail labels or multiple IMAP locations of one logical message as duplicate records to delete. This extends the existing contact merge and import-time duplicate reviews. **Checks:** false-positive fixtures, same-message multiple locations, recurring events, task hierarchies, stale records, partial failures, and undo. **Docs:** describe matching criteria, supported owners, and recovery. Evidence: F0 and the documented Deduplicator.

- [ ] **E33 — Inbox category tabs and classification rules.** Add Primary, Social, Promotions, Updates, and other configured inbox tabs, counts, manual reassignment, and persistent sender/domain classification rules. Map provider categories where supported and use explicit local classification elsewhere; expose classification as a rule condition/action. Keep existing local tags and Outlook categories as separate metadata. **Checks:** provider mappings, manual override precedence, resync persistence, unified-account counts, and keyboard navigation. **Docs:** explain local versus synchronized categories and reclassification. Evidence: F0/F2.

- [x] **E34 — Pin mail conversations at the top of the list.** Persist local pin state, add Pin/Unpin to selection menus and the command palette, and sort pinned conversations ahead of normal date order in folder and unified views. Preserve pin state through resync and backup, with stable ordering and pagination. Stars and importance remain independent. **Checks:** account-scoped identity, mixed pinned/unpinned pages, new mail arrival, undo, and restart. **Docs:** explain pin scope and its relationship to stars. Evidence: F1.

- [ ] **E35 — Favorite folders and local folder appearance.** Let users pin any account folder/label into Favorites, reorder favorites, set a display alias, and remove a favorite without deleting its folder. Add local icon/name colors for non-Gmail folders and visibility preferences; retain existing Gmail color synchronization. Replace the sidebar's first-twelve-label limit with access to the full folder tree. **Checks:** cross-account names, folder rename/move/delete, stale favorites, ordering after restart, and Gmail/local color behavior. **Docs:** distinguish display preferences from provider folder changes. Evidence: F0 and the folder/favorites documentation.

- [ ] **E36 — Configurable offline download and synchronization scope.** Add per-account and per-folder choices for full offline content, headers/on-demand bodies, attachment downloading, and a date window, with overrides and Load more/Load all. Report which data is available offline and whether search covers the whole mailbox. Preserve drafts, pending writes, and Local Folders during cache eviction; changing cache policy must not delete provider mail. **Checks:** policy transitions, shared message locations, offline reads, search completeness, storage reclamation, and interrupted downloads. **Docs:** explain storage, network, and search tradeoffs. Evidence: F3.

- [x] **E37 — Editable keyboard shortcuts.** Introduce a persisted command/keymap registry and Settings editor with search, conflict detection, clear/reset, and platform defaults. Support remapping mail, navigation, editor, and Quick Action commands, and show current bindings in menus and command-palette results. Keep typing and accessibility navigation safe when a text field is focused. **Checks:** collisions, focus contexts, saved overrides, reset/migration, and Windows/macOS/Linux modifiers. **Docs:** generate or update the shortcut reference from the registry. Evidence: F0 and the shortcuts documentation.

## Accounts and shared workspaces

- [ ] **E38 — POP3 accounts with SMTP sending and retention settings.** Add POP3 setup, TLS/STARTTLS connection testing, credential storage, UIDL checkpoints, resumable download into an account folder tree or Local Folders, and the existing SMTP Outbox integration. Provide leave-on-server, remove-after-N-days, and remove-when-deleted policies with clear server effects. **Checks:** disposable POP3/SMTP fixtures covering UIDL stability, reconnect/restart, repeated downloads, retrieval failure, retention, and authentication/TLS errors. **Docs:** explain POP3's download model and migration from other clients. Evidence: F4.

- [ ] **E39 — On-premises Exchange/EWS accounts.** Add an Exchange account type with autodiscovery/manual endpoint setup, supported authentication, and mail/folder synchronization and sending. Connect Calendar and Contacts to the existing normalized productivity stores, with capability reporting and revision-aware writes. Keep Microsoft 365's existing Graph route available; report unsupported server/authentication combinations explicitly. **Checks:** EWS service fixtures for discovery, paging, incremental checkpoints, expired sessions, conflicts, and durable queued changes, followed by a documented live-server validation matrix. **Docs:** cover supported server versions, account setup, and provider limitations. Evidence: F5.

- [ ] **E40 — Shared/delegated mailboxes, delegation permissions, and public folders.** Add discovery or explicit attachment of delegated mailbox/folder trees, owner and permission indicators, and permitted folder/mail/calendar operations. Add an Exchange public-folder browser/subscription flow and delegation read/edit controls where the server supports them. Key caches and queued actions by the owning mailbox so similarly named folders cannot collide. Build on E39 for EWS and extend the current Graph connector for supported shared-mailbox operations. **Checks:** read-only versus writable shares, revoked access, send-as versus send-on-behalf, owner isolation, and partial failures. **Docs:** explain delegation setup and effective permissions. Evidence: F0/F5.

- [ ] **E41 — Organization directory and offline address book.** Add directory/GAL lookup to recipient selection and Contacts, including people, groups, and resources, with a clearly marked read-only source. Support a refreshable offline address-book cache for servers that expose one; retain personal contact editing and cached-mail suggestions. **Checks:** directory pagination, denied permissions, ambiguous names, group/resource addresses, offline lookup, and atomic cache refresh after failure. **Docs:** specify supported directory backends, consent/setup, and cache freshness. Evidence: F5/F6.

## Notes and tasks

- [x] **E42 — Rich Notes editor with inline pictures.** Extend plain-text notes with sanitized rich content, headings, lists, links, tables, and managed inline images. Reuse the existing attachment store and mail editor/sanitizer where appropriate; migrate existing plain-text notes without changing their text. Preserve existing folders, tags, colors, pinning, and archive behavior. **Checks:** paste sanitization, inline-image persistence, editing/search, old-backup migration, and portable restore. **Docs:** describe formatting, image storage, and backup compatibility. Evidence: F0/F7 and the notes documentation.

- [ ] **E43 — Server-synchronized Notes and vNote import.** Add provider-owned Notes folders for compatible CalDAV VJOURNAL and Exchange Notes services, with discovery, read-only detection, incremental sync, offline writes, and conflict review. Keep local Notes available and provide explicit copy/move between owners. Add vNote file import with a preview and duplicate handling, using the existing local-data backup for exact Aerio restore. Depends on E39 for Exchange and E42 for rich-body preservation. **Checks:** service fixtures for revisions/deletions, restart recovery, attachments, preserved server properties, and malformed/duplicate vNote files. **Docs:** list server/format support and explain conflicts, migration, and account removal. Evidence: F5/F7/F8/F12.

- [ ] **E44 — Task start dates, reminders, progress, tags, and attachments.** Extend local and connected task contracts/editors with start date/time, independent reminders with dismiss/snooze, percent complete, categories, and managed attachments. Preserve existing Microsoft task status, recurrence, priorities, and subtasks. Map supported provider fields natively and label local-only fields instead of silently dropping them. Persist reminder delivery across restart and recurrence. **Checks:** due/start time zones and DST, missed/snoozed reminders, recurring completion, provider round trips, attachment cleanup, and backup migration. **Docs:** publish the provider capability matrix and reminder behavior. Evidence: F9.

- [ ] **E45 — CalDAV tasks and iCalendar task interchange.** Synchronize VTODO collections into Tasks alongside Google Tasks/Microsoft To Do, including task-only and mixed VEVENT/VTODO collections, ETags, incremental sync, offline queues, and conflict review. Add task import/export in .ics with start/due dates, completion/progress, priority, recurrence, categories, and reminders; retain unsupported properties or explain edit restrictions. Reuse E44's extended fields and the existing DAV/interchange infrastructure. **Checks:** separate calendar/task routing, recurrence exceptions, provider conflicts/deletions, restart recovery, duplicate import, and round-trip fixtures. **Docs:** cover supported servers, VTODO mappings, and interoperability limits. Evidence: F8/F9 and the task protocol/interchange documentation.

## Integrations and automation

- [x] **E46 — Dropbox, ownCloud, and Nextcloud cloud attachments.** Implement these storage connectors behind the existing cloud-attachment interface, with independent account connection, file upload/picker, sharing-link creation, visible audience/permissions, cancellation, and recoverable upload state where supported. Show provider-specific capabilities for password/expiry and link changes, and reuse pre-send link checking. Google Drive and OneDrive already exist. **Checks:** connector fixtures for authentication, upload interruption, sharing permissions, link expiry/revocation, and disconnect. **Docs:** provide provider setup and sharing-capability comparisons. Evidence: F10.

- [x] **E47 — Functional Zoom and Webex meeting connectors.** Replace the unavailable connector placeholders with authorized account setup, scheduled meeting creation, supported meeting edits/cancellation, and join details in Calendar and invitations. Reuse the durable creation identity so retrying a calendar save cannot create a second conference; preserve existing Google Meet/Teams behavior. **Checks:** mocked connector lifecycle, duplicate-prevention after uncertain outcomes, event edit/delete coordination, revoked credentials, and a live-provider validation matrix. **Docs:** update [online meetings](docs/online-meetings.md) with setup, scopes, host permissions, and supported lifecycle operations. Evidence: F11.

- [ ] **E48 — Opt-in external automation through MCP.** Expose a documented local stdio MCP bridge for account/folder inventory, mail/conversation search and reading, attachment access, opening messages in Aerio, and mail/draft actions through the existing service boundaries. Provide read-only access and separately enabled write/send/delete capabilities, operation effect descriptions, connection controls, and revocation; respect app lock and shutdown. This extends external access beyond the internal Electron preload API. **Checks:** protocol/schema validation, pagination, account scoping, disabled capabilities, locked/closed app behavior, duplicate send prevention, and redacted diagnostics. **Docs:** document installation, client configuration, available tools, and access controls. Evidence: F0 and the eM Client MCP documentation.
